Timestamp confidence

{{ timestamp_chart }}
There is no such thing as the forex market timestamp — FX is decentralised, and every provider stamps in whatever zone it likes. Storage is UTC; this is how sure we are of each instant.

Forecast provenance

{{ forecast_chart }}
A forecast is point-in-time only if we held it before the release. Scraping a calendar page today can capture numbers the market never saw, which silently inflates every result downstream.
