What the buttons do

Fetch
Queues a job: request the source, write the payload to data/raw/ content-hashed, normalise it, merge it on the identity key, and record what changed. Idempotent — re-running never duplicates a release.
Preview
The same fetch and the same parsing, but nothing is written. The run page then shows a sample of the actual rows. Use it before committing a new source or a new configuration to the dataset — a coverage chart cannot tell you a column is fully populated with the wrong number.
Force
Overrides the fetch-policy cooldown stored on the source. Appears only while a cooldown is active. The ForexFactory feed returns HTTP 429 when polled hard, which is why the cooldown exists.
Re-parse
Re-runs the current normaliser over the latest stored payload with no network request. This is why raw snapshots are kept: a parser fix is a re-parse, not a re-crawl. It re-uses the original capture time, so point-in-time forecasts are not silently downgraded.
Re-seed
Rewrites the source register, the seven majors, release groups and the known market dislocations. Safe to re-run: it updates descriptions and leaves health, history and hand-edited mappings alone.
